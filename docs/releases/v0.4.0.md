# Kafka Lens v0.4.0

发布日期：2026 年 11 月 3 日

本版本新增完整的中文 / English 页面切换，并确保切换语言时不重建 Kafka 会话、不清空表单、弹窗、最近一小时历史或 Lag 持续判定状态。

## 更新清单

- 首次访问跟随浏览器首选语言；中文语言显示中文，其余语言显示 English。
- 顶部栏右侧新增「中文 / EN」切换，窄屏显示「中 / EN」，支持鼠标和键盘操作。
- 用户选择保存在当前浏览器的站点存储中；清除站点存储后重新跟随浏览器语言。
- 概览、Topics、Consumer Groups、集群设置、Lag 规则、飞书告警、弹窗、图表、状态、校验和安全错误均支持即时切换。
- Kafka Lens、Topic、Consumer Group、Lag、Offset、Partition、Broker、SASL、SSL 等品牌和技术术语保持英文；集群名、Topic 名、Group ID 和用户输入原样显示。
- 语言切换仅更新界面文案，不改变当前路由、刷新频率、Kafka session、表单草稿、弹窗状态、历史数据或告警判定。
- 后端错误使用受控翻译，不把原始错误、Kafka 凭据或飞书 Token 回显到页面。
- 修复 English 模式下消费组历史区域样式失效、浏览器语言回退、顶部栏断连布局及英文单复数问题。
- 三个平台的部署包均内置中文和 English 资源，无需额外配置环境变量或下载语言包。

## 配置与启动

以 Linux AMD64 为例，将归档和校验文件放在同一目录：

```bash
sha256sum -c kafka-dashboard-v0.4.0-linux-amd64.tar.gz.sha256
tar -xzf kafka-dashboard-v0.4.0-linux-amd64.tar.gz
cd kafka-dashboard-v0.4.0-linux-amd64
cp .env.example .env
chmod 600 .env
```

编辑 `.env`，至少确认以下配置：

```dotenv
DATABASE_URL=sqlite://data/kafka-dashboard.db?mode=rwc
KAFKA_DASHBOARD_BIND=127.0.0.1:3000
KAFKA_DASHBOARD_WEB_DIR=web
RUST_LOG=info
```

然后启动并查看状态：

```bash
./start.sh
./start.sh status
```

默认访问 `http://127.0.0.1:3000`。停止或重启：

```bash
./start.sh stop
./start.sh restart
```

macOS 使用 `shasum -a 256 -c <校验文件>`。如需让其他机器访问，请通过受控内网或带认证的 HTTPS 反向代理提供服务，不要直接暴露到公网；程序没有内置登录功能。SQLite 会明文保存 Kafka 凭据和飞书 Token，须限制 `.env`、数据库及备份的文件权限。

## 从 v0.3.0 升级

先执行旧目录的 `./start.sh stop`，备份旧目录中的 `.env` 和 `data/`，再将它们以原有私有权限复制到新的 v0.4.0 平台目录。不要覆盖仍在运行的旧目录。本版本不新增数据库迁移，原有集群、Lag 规则和飞书告警配置可继续使用。

启动后首次打开页面会跟随浏览器语言；顶部栏可随时切换「中文 / EN」。语言选择只保存在当前浏览器，不写入数据库。
