# Lag 状态判定

在集群设置中调整默认区间，或为特定 Consumer Group 和 Topic 添加覆盖规则。两者均从已有选项中选择，使用覆盖规则的表格行带有自定义标记。

| 状态 | 默认区间 |
| --- | --- |
| 正常 | 0–999 |
| 积压 | 1,000–4,999 |
| 高 Lag | ≥ 5,000 |

正常上限必须小于高 Lag 起始值，两者均为非负整数。默认持续超限时间为 30 秒，可以设为 0。

从首个有效超限样本起，连续超限达到设定时长才显示积压或高 Lag。采集异常和未提交立即显示。恢复正常、隐藏页面、断开连接、重新建立会话、切换集群或修改规则都会重置计时。

例如，Flink 每分钟随 checkpoint 提交一次 Offset，提交之间的短暂 Lag 可能较高。可以给这个 Group 和 Topic 单独设置正常上限与持续超限时间，使表格反映业务关心的持续积压。页面规则与[飞书增长告警](feishu-alerts.md)分别配置。
