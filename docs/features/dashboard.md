# 集群概览与采集

在概览页查看当前集群的指标和总 Lag 趋势。Lag 分布按 Consumer Group 汇总其各个 Topic 的已知 Lag，有未知分区时会标记数据不完整。点击「需要关注」表格中的消费组，可进入对应 Group 和 Topic 的详情。

## 刷新与历史

顶部栏可手动刷新，也可选择 3、5 或 10 秒自动采样。折线图保留当前页面内存中最近一小时的样本，刷新页面会清空历史。

## Kafka 连接何时释放

仅保存 Kafka 连接配置不会保持 Kafka 连接。进入仪表盘或配置规则时创建按需监控会话，租约为 15 秒，快照请求续租。同一会话同时只允许一个采集，重叠请求返回 409。后台每 5 秒清理过期会话；隐藏页面停止仪表盘轮询，页面离开、切换集群和删除集群会主动关闭对应会话，关闭请求未送达时由租约兜底。已配置 Token 且启用飞书规则的后台连接独立于浏览器租约；停用全部规则、清除 Token 或删除集群会停止该监控。SIGINT / SIGTERM 会等待在途监控采集、已接受通知和 Kafka 资源释放后退出。

窄屏支持表格内部横向滚动。页面布局与配色可参照[已确认的页面 Demo](../ui/approved-dashboard-demo.html)。
